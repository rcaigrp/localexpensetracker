# LocalExpenseTracker

A local expense tracker with category support and budget alerts.

## Goal
Create a local expense tracker with category support and budget alerts.

## Acceptance Criteria
1. `expense_tracker` module exists and can be imported.
2. `add_expense` function records expenses with category and amount.
3. `get_spending_by_category` returns a dict of category totals.
4. `check_budget_alert` returns True if spending exceeds a threshold.
